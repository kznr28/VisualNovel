### 音源の測定記録

全曲が48 kHz・ステレオのMP3。長さと音声ストリームのビットレートはFFprobe、Integrated LUFSとTrue PeakはFFmpegの `loudnorm` で測定した。SPは浮動小数点PCMにデコードしたサンプルのピーク（dBFS）、TPはTrue Peak（dBTP）。「静音」は両チャンネルとも−55 dBFS以下の区間を、先頭・末尾の各サンプルから連続して数えた秒数。0.000はミリ秒未満を含む。

デコード後の曲尺は原本とゲーム用で一致する。4曲とも、原本・ゲーム用の双方でフルスケールに達したサンプルは0。合計配布容量は17,230,112 byte（16.43 MiB）。

タイトル曲は音声フレームをコピーし、埋め込み画像と制作メタデータのみ除去した。末尾約1.41秒の静かな余韻を含めて全曲ループする。本編3曲は先頭350 msと末尾60 msにフェードをかけ、つなぎ目の波形の段差を抑えた。エンコード前の固定ゲインは夕暮れ0 dB、屋上−1.1 dB、夜の図書室＋0.6 dB。シーン間のフェードアウトは250 msで、次の曲は元の曲を停止してから開始する。

### 再生、セーブ、PWA

- `js/music.js` で音楽を登録する。タイトルは `MainScreenMusic`、本編はMonogatariの `play music … with loop` と `stop music … with fade 0.25` を使う。音量の初期値は40%。保存済みの音量設定を引き継ぐ。
- 音楽は保存済みの背景から復元する。以前のセーブが使う背景色の別名も同じ背景画像へ解決する。ロード・分岐をまたぐロールバックでは、その場面の曲を先頭から再生する。
- 起動時は背景と登録済み立ち絵をプリロードし、BGMは使用時に取得する。自動再生が制限される環境ではタイトル上のMonogatari標準の再生案内を押す。
- Service Workerは完全なMP3をURLごとに保存し、部分取得には必要なバイト範囲を返す。初回インストール前から進行中の部分取得はネットワークで完了させる。オフライン再生の対象は取得・キャッシュ済みの曲。未取得の分岐も本文を読み進められる。同名音源を差し替えるときは `service-worker.js` の `musicCache` の版を更新する。
